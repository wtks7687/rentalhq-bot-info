RentalHQ Bot

Private internal tool. Last updated 22 November 2026.

RentalHQ Bot is a private Telegram bot used by a single property agent to prepare residential tenancy agreements. It is not offered to the public.

Privacy Policy

What the bot handles

Details the agent sends for a tenancy: names, identity card numbers, phone numbers, addresses, rental amounts, dates and bank account numbers of the landlord and tenant.

How it is used

  • The details are used only to fill in the tenancy agreement and send it back to the agent.
  • The text of the agent's message is processed by the Anthropic Claude API to read the details.
  • Finished agreements and the case currently being prepared are saved to the agent's own Google Drive.

Google user data

The bot requests only the drive.file permission, so it can see and change only the files it creates itself. It cannot read any other file in the Google Drive. Google user data is not sold, shared with third parties, or used for advertising, and its use follows the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Agreements stay in the agent's Google Drive until the agent deletes them. Access can be removed at any time at myaccount.google.com/permissions.
